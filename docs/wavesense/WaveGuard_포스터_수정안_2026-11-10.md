## 포스터 본문

### 제목

**WaveGuard — Wi-Fi 신호로 CCTV 사각지대의 사람을 찾는 보조 감지 시스템**

### ■ 1. 주제 선정 배경

**카메라가 못 보는 곳에도 사람은 있다.**

가구나 벽에 가려진 곳, 사생활 때문에 카메라를 둘 수 없는 곳은 CCTV로 확인하기 어렵다. Wi-Fi 신호의 변화로 사람이 있는지, 방의 어느 구역에 있는지를 추정해 CCTV 사각지대를 보완하고자 한다.

### ■ 2. 핵심 원리

**사람이 있으면 Wi-Fi 신호가 흔들린다.**

Wi-Fi 신호는 벽·가구·사람에 부딪혀 여러 경로로 도착하고, 수신기는 이 변화를 CSI(채널 상태 정보)로 측정한다. 사람이 있으면 신호 경로가 바뀌고, 움직이면 CSI가 크게 흔들린다. 이 패턴을 AI로 학습해 사람의 존재와 위치 구역을 판정한다.

[감지에 영상 불필요] [가림·벽 너머 감지] [조명과 무관]

### ■ 3. 시스템 구성

**저가 ESP32 보드 4대와 노트북 한 대로 구성한다.**

(하드웨어)

- 송신 보드 1대: Wi-Fi 패킷을 계속 송신
- 수신 보드 3대: 방 모서리에서 CSI 측정
- 노트북: 신호 수집·분석·결과 표시
- 웹캠 1대: CCTV 역할, 사각지대 감지 비교용

(배치)

- 3m×3m 이상 실내 공간을 2×2, 총 4개 구역으로 나눈다.
- 보드는 방 네 모서리, 높이 약 1m에 둔다. 송신·수신 보드를 일직선으로 두지 않는다.
- 구역 4는 장애물로 가려 웹캠이 볼 수 없는 사각지대로 만든다.

### ■ 4. 주요 기능 및 동작 과정

**Wi-Fi 신호만으로 사람이 있는 구역을 찾아 평면도에 표시한다.**

[시스템 일러스트]

1. 신호 수집: 수신 보드 3대의 CSI를 노트북에 동시 저장
2. 전처리: 진폭 계산, 빈 채널 제거, 4초 단위 분할
3. 판정: 학습 모델로 사람의 존재 여부와 위치 구역(1~4) 판정
4. 화면 표시: 평면도에 사람이 있는 구역과 판정 신뢰도 표시, 웹캠이 놓친 사각지대 감지 강조

### ■ 5. 개발 계획 및 한계·해결 방안

(구현 순서)

1. 공개 ESP32 데이터로 존재 감지·위치 구분 가능성 확인 — **완료**
2. 보드 2대로 사람이 지나갈 때 신호가 변하는지 확인 (장비 점검)
3. 보드 4대로 학습 데이터를 2일간 수집하고, 새 참여자를 포함한 테스트 데이터 수집
4. 카메라 단독, Wi-Fi 단독, 결합 방식의 사각지대 감지 성능 비교

확장 목표: 사람의 자세(스켈레톤) 추정

(사전 검증 결과 — 공개 ESP32 데이터)

- 존재 감지: 가림 없음 100%, 벽 너머 97.4~97.5%
- 위치 구분: 위치 5곳 약 91%, 벽 너머 방 5개 약 85%

(한계와 해결)

| 확인한 한계 | 해결 방안 |
|---|---|
| 같은 날 데이터로 평가하면 점수가 부풀려짐 (방 구분 99% → 녹화별 기본 신호 제거 후 85%) | 학습과 다른 날 수집한 데이터로 평가 |
| 학습과 다른 환경에 그대로 적용하면 정확도 56.82~69.57%로 하락 | 실제 실험 공간에서 직접 수집해 학습 |
| 송신·수신을 일직선으로 두면 양 끝 위치를 혼동 | 수신 보드를 방 모서리 여러 방향에 배치 |
| 공개 데이터는 걷는 사람 위주라 정지한 사람은 미확인 | 수집 세션에 '가만히 서기' 구간 포함 |
| 빈 방 표본이 적으면 정확도만으로는 성능이 부풀려짐 | 재현율과 오탐을 함께 보고 |

### ■ 6. 활용 분야 및 기대 효과

- 보안: CCTV 사각지대 보완
- 돌봄: 독거 가구 재실 확인
- 스마트홈: 사람이 없으면 조명·냉난방 자동 제어
- 헬스케어: 영상 없이 활동량 확인 (확장 검토: 낙상 감지)

감지 단계에서 얼굴 영상이 필요 없어 사생활 부담을 줄이고, 가려지거나 어두운 곳에서도 사람의 존재를 확인할 수 있다.

## "원리와 근거" 탭 수정안

### 3. 카메라와 비교한 장점

- 감지 단계에서 영상이 필요 없어 얼굴 등 개인정보 부담이 적습니다. 실험의 웹캠은 비교와 정답 확인에만 사용합니다.
- Wi-Fi 신호는 벽과 장애물을 지나므로 가려진 곳도 감지할 수 있습니다. 공개 데이터에서 벽 너머 존재 감지 97% 이상을 확인했습니다.
- 빛이 필요 없어 어두운 곳에서도 동작합니다.
- 저가 ESP32 보드 4대와 노트북 한 대로 구성할 수 있습니다.

### 4. 처리 방식

ESP32 원본 신호 → 진폭 계산 → 빈 채널 제거 → 4초 단위 분할 → 특징 추출 → 모델 학습·판정

※ 공개 데이터 기준으로는 패킷당 숫자 256개, 빈 채널 20개입니다. 사용할 ESP32-C5 보드에서는 도착 후 다시 확인합니다.

### 발표 멘트 (원리)

Wi-Fi 신호는 벽이나 사람에 부딪혀 반사되면서 여러 경로로 도착합니다. 수신기는 이 신호가 어떻게 바뀌어 도착했는지를 CSI라는 정보로 측정할 수 있습니다. 사람이 있으면 신호 경로가 바뀌고, 움직이면 CSI가 크게 흔들립니다. 저희는 이 패턴을 AI로 학습해, 영상 없이 사람이 있는지와 방의 어느 구역에 있는지를 판정합니다.

### 발표 멘트 (근거)

보드를 사기 전에 공개된 ESP32 데이터로 먼저 확인했습니다. 사람이 있는지는 벽 너머에서도 97% 이상 구분했고, 위치 다섯 곳은 약 91%로 구분했습니다. 검증 중에 벽 너머 방 구분이 처음에는 99%로 나왔는데, 모델이 위치가 아니라 녹화 시간대의 신호를 외운 것이었습니다. 이 영향을 빼자 85%가 됐습니다. 또 학습한 공간과 다른 곳에 그대로 쓰면 정확도가 60% 안팎으로 떨어졌습니다. 그래서 실제 실험 공간에서 직접 데이터를 모으고, 학습과 다른 날 데이터로 평가합니다.

### 발표 멘트 (시스템 구성)

방 네 모서리에 저가 ESP32 보드를 하나씩 둡니다. 한 대가 Wi-Fi 신호를 보내고, 나머지 세 대가 받습니다. 일직선으로 두면 위치를 혼동하기 때문에 여러 방향에서 받도록 했습니다. 방은 네 구역으로 나누고, 한 구역은 장애물로 가려 카메라가 볼 수 없는 사각지대를 만듭니다. 이 구역에 사람이 있을 때도 Wi-Fi로 찾아내는 것이 목표입니다.

### 예상 질문 대응

- **보드가 2개뿐이지 않나요?** 현재 장비 점검용 2대를 확보했고, 4대 배치를 위해 추가 구매를 진행합니다. (팀 확정 후 사용)
- **자세 추정은 하지 않나요?** 1차 목표는 존재와 구역 판정이고, 자세 추정은 이 단계가 검증된 뒤 확장 목표로 진행합니다.
- **이미 Wi-Fi 감지 제품이 있지 않나요?** 구역별 감지 자체는 상용 제품에도 있습니다. 저희는 같은 조건에서 카메라 단독, Wi-Fi 단독, 결합 방식을 비교해 CCTV 사각지대에서 실제로 미감지가 얼마나 줄어드는지를 보여주는 데 집중합니다.
