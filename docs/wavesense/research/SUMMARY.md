# WaveSense 방향 정리 – 자세추정 필수 전환 (2026-11-19)

## 1. 범위
- 필수: 재실 감지, 구역 판별, 자세 분류(없음/서기·걷기/앉기/눕기), 인원 0/1/2명 이상
- 도전 목표: 같은 방 조건에서 간소화된 스켈레톤 데모
- 제외: 다인원 동시 자세추정 (ESP32 기반 선행 사례 없음)

## 2. 논문 기준 한계
- 인원추정: ESP32 4링크로 5명 ±1 오차 내 89.8%, 10명 81.8% (Wi-CaL)
- 최대 보고 사례는 30명이나, 15명 넘으면 오차 약 2명, 20명대에서 포화
- 링크 수가 중요 (1링크 44% → 6링크 99% 이상)
- 다인원 자세추정은 최대 3명 (Person-in-WiFi 3D, 수신기 3대, ESP32 아님)

## 3. 장비
- 보유 중인 ESP32-C5 유지 (2.4/5GHz 지원)
- 외장안테나는 U.FL 커넥터 있는 -1U 모듈 필요, 2.4/5GHz 겸용 안테나 사용
- 공식 ESP32-C5-DevKitC-1은 PCB 안테나라 외장안테나 불가
- 후보: DFRobot FireBeetle 2 ESP32-C5-U (약 $8.40, 동봉 안테나 2.4GHz 전용), UeeKKoo ESP32-C5 WROOM-1U 보드 (약 $20, 겸용 안테나 포함). 해외가 기준, 배송·관세 제외
- 장비 교체보다 보드를 늘려 링크 수 확보가 효과적
- 학습용 정답 라벨: 웹캠 + YOLO-Pose/OpenPose (아이폰 라이다는 1명만 가능)

## 4. 새로운 사람 대응
- 설치 시 1회 보정 필요 (빈 방/1명/2명 이상/자세별), 가구 이동 시 재보정
- 처음 보는 사람 기준 자세 정확도는 현실적으로 55~65%
- 학습 인원 3명이면 25~33%p 하락, 10명이면 3~5%p 하락
- 실제 인원 8~10명(가능하면 15명 이상) 수집, 2~3명은 최종 테스트용으로 분리

## 5. 가상 데이터
- 웹캠 스켈레톤 기반 가상 CSI: 처음 보는 사람 기준 최대 약 10%p 향상 (CM-GR)
- 단순 증강: 사람 변화에는 효과 미미(+0.87%p, RFBoost), 방·장비 변화에는 15~22%p 향상 (TU Wien ESP32)
- 보조 용도로만 사용, 평가는 반드시 실제 사람 데이터로

## 6. 다음 할 일
- 포스터·공설 문서에 자세추정 필수 반영
- 공개 데이터셋(3DO)으로 자세 분류 사전 검증
- -1U 보드·안테나 구매
- 논문 수치는 원문 재확인 후 포스터 반영
