# WaveGuard 오프라인 데모

보드 수령 전 CSI 데이터 처리와 시각화 흐름을 확인하기 위한 브라우저 기반 데모입니다. 이 문서는 2026년 10월 27일 제작한 데모의 기능, 실행 방법, 검증 범위와 다음 실험 방향을 정리합니다.

**현재 단계는 합성 데이터 기반의 시각화·재생 데모입니다. 실제 사람의 존재·위치·관절을 추정하는 AI 모델이나 감지 성능을 검증한 단계는 아닙니다.**

## 구현 기능

- 내장 합성 CSI 데이터 재생
- ESP32 CSI CSV 파일 가져오기
- CSI 신호 파형과 시간에 따른 변화량 표시
- 재생·일시정지, 재생 속도 조절, 구간 이동

## 실행 방법

실행 파일은 별도로 공유한 데모 ZIP을 사용합니다. 이 저장소에는 안내 문서만 포함됩니다.

1. 데모 ZIP을 PC에서 압축 해제합니다.
2. `index.html`을 브라우저로 엽니다. 별도 설치나 서버 실행은 필요하지 않습니다.
3. 내장 합성 데이터로 재생을 시작하고 파형과 변화 점수를 확인합니다.
4. 샘플 CSV 또는 사용 안내의 형식에 맞는 ESP32 CSI CSV를 가져옵니다.
5. 재생 속도와 구간을 바꾸며 신호 변화를 살펴봅니다.

ZIP에는 실행 파일, 사용법, 샘플 CSV, 소스 코드와 테스트가 포함되어 있습니다. 모바일 파일 미리보기에서는 실행이 제한될 수 있으므로 PC 브라우저 사용을 권장합니다.

## 검증 범위

제작 당시 데이터 파싱·계산 테스트 15개와 재생 상태 자동 검사를 통과했습니다. 실제 브라우저 화면의 표시와 조작은 아직 확인하지 않았습니다.

- 내장 데이터는 실제 보드 측정값이 아닌 합성 데이터입니다.
- 화면의 점수는 신호 변화량을 나타내며, 사람 감지 확률이나 AI 정확도가 아닙니다.
- 실제 ESP32 보드 데이터와의 연동 및 감지 성능은 검증 전입니다.
- 정지한 사람, 벽 뒤 위치, 다중 인원과 관절 추정 성능을 보장하지 않습니다.

## 장비 확보 후 실험 방향

1. **화면 점검:** PC 브라우저에서 CSV 가져오기, 파형 표시, 재생 조작을 확인합니다.
2. **실측 데이터 수집:** 송신·수신 보드 2대로 배치를 고정하고 빈 공간, 사람이 걷는 상황, 가만히 앉아 있는 상황을 각각 기록합니다.
3. **신호 비교:** 실제 상황 기록과 파형·변화량을 비교하고, 반복 측정에서도 차이가 나타나는지 확인합니다.
4. **평가와 확장:** 오탐·미탐 및 환경 변화의 영향을 확인한 뒤 구역별 위치 구분으로 확장할 수 있을지 검토합니다.

첫 실험의 목표는 안정적인 CSI 수집과 빈 공간·움직임 간 차이를 확인하는 것입니다. 정지한 사람이나 위치 추정은 별도로 검증해야 합니다.
