## 실행되지 못한 검사
- 실제 Chromium UI 테스트와 화면 캡처: 브라우저가 페이지를 열기 전 실행 환경의 소켓 권한 제한으로 종료. 승인된 확장 실행도 샌드박스 초기화 단계에서 실패했습니다.
- 따라서 `browser_test.py`는 준비/구문 검사만 했으며 실제 브라우저 통과로 표시하지 않습니다. 화면 레이아웃, 모바일 오버플로, 실제 브라우저 네트워크 요청 여부는 실행 검증하지 못했습니다.
- 실제 ESP 보드/시리얼/실측 CSV/사람 감지 정확도 검증 없음.

`app_test.js`는 브라우저 화면 렌더링 검증을 대체하지 않습니다. 허용된 로컬 개발 환경에 Python Playwright와 Chromium이 있으면 `python browser_test.py`로 실제 브라우저 검증을 재현할 수 있습니다. 데모 실행 자체에는 이 개발 도구가 필요하지 않습니다.
